uitree in the browser

The same counter.rc twice, each in its own h9 machine in a Web Worker (h9's browser host, its own 386 CPU), with $ui served by the uitree core in wasm on this page. Left: the GPUI renderer on gpui_web's canvas. Right: the terminal renderer drawing into xterm.js. Click the buttons, or press =, - and 0 with a panel focused.

This browser lacks JavaScript Promise Integration, which h9 and the core need: Chrome or Edge 137 or later.
