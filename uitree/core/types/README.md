# types

The component catalog as data: one directory per type, `NAME/spec`, in the
descriptor grammar of [components.md](../../protocols/components.md#the-descriptor).
A directory may also hold an example data file named after its format
(`items`, `rows`, ...).

Owner: workstream W1 (types). `uitree-headless` embeds every descriptor
here. A renderer passes the subset it implements in `UitConfig.types`, and
the core checks the two agree at `uit_create`.

`style-words` and `theme-tokens` live here too, generated by the GPUI
renderer's `style-gen` tool from GPUI's source (one `name argkind` or
`name light dark` per line), so the core can validate style without
knowing GPUI.
